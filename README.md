# Stickman Arena

A small single-player stickman action game inspired by fast arcade stickman fighters.

## How to run

Open `index.html` directly in a browser, or serve the folder with a local HTTP server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Controls

- A / D or Left / Right: Move
- W / Up / Space: Jump
- J or K: Attack
- R: Restart after defeat

## Goal

Defeat incoming stickmen, survive longer, and chase a higher score.
